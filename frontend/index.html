How to read this table
  • N mentions — the papers scanned for that organism name the gene (the link opens its NCBI Gene page).
  • ortholog present — those papers do not name it, but OrthoDB lists a member of the same ortholog group in that organism.
  • none in OrthoDB — OrthoDB lists no member of the group in that organism.
  • not checked — no OrthoDB group could be found for the gene (hover for the reason). This does not mean the gene is missing.
  • Each row is an OrthoDB ortholog group, so it can include closely related paralogs. “Not discussed” only means the scanned papers do not name the gene.
